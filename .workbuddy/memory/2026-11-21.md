- `src/main.rs` 已从脚手架改为带侧边栏的播放器主界面：

- 自定义标题栏（所有平台隐藏系统标题栏），`TITLEBAR_HEIGHT = 40`：
  - `WindowOptions.titlebar = TitlebarOptions { appears_transparent: true, traffic_light_position }` 隐藏 macOS/Windows 系统标题栏；
  - `window_decorations: WindowDecorations::Client` 隐藏 Linux 服务端装饰；
  - `app_owns_titlebar_drag: true` + 标题栏 `on_mouse_down` → `start_window_move()` 实现拖动，双击 `click_count == 2` → `titlebar_double_click()` 切换最大化。
  - macOS：系统红绿灯 overlay，`traffic_light_position = point(px(16.), px((40-14)/2))`（坐标为按钮左上角），品牌区 `pl(px(78.))` 避让。
  - Windows/Linux：lucide 图标自绘按钮 `Minus` / `Maximize2`·`Minimize2`（依 `window.is_maximized()` 切换）/ `X`；分别调用 `minimize_window()`、`zoom_window()`、`app.quit()`。
  - Windows/Linux 下 icon + 品牌名贴标题栏最左端（无左内边距）。
  - 布局：外层 `div().flex().flex_col()`，标题栏在 `SidebarLayout` 之上（标题栏容器套在 sidebar 上）。
- 平台判断用运行时 `cx.platform_info().is_mac()`（Context deref 到 App）。

## 标题栏搜索 + Spotlight 搜索弹层

- 标题栏改为三段式 flex 布局：左品牌区 `flex_1`、中搜索触发框 `w(px(320.))` 固定宽、右窗口按钮 `flex_1` 右对齐；左右等宽使中间精确居中。
- 搜索触发框：放大镜 `LucideIcon::Search` + 文案「在这里搜索歌曲 歌手 专辑信息」，`on_mouse_down` 调 `cx.stop_propagation()` 避免触发标题栏拖动。
- Spotlight 状态：`Player { search: Entity<InputState>, search_open: bool }`，`Player::new(window, cx)` 构造，`cx.new(|cx| InputState::new(window, cx).placeholder(...))`；`cx.subscribe(&search, ...)` 监听 `InputEvent`，PressEnter 选中首项，其余只 `cx.notify()`。
- 打开：`open_search` 清空输入 → `window.focus(state.focus_handle(cx))`（需 `Focusable as _`）→ notify。
- 弹层：`div().absolute().inset_0()` 居中遮罩（`theme.colors.overlay` + `occlude()`），面板 `w(px(560.))` + `theme.shadows.lg`；点遮罩关闭、面板 `stop_propagation`；`on_key_down` 处理 Escape（输入组件本身不消费 Escape，事件会冒泡到遮罩）。
- 搜索结果目前过滤 `Destination` 导航项（中英文名/key 匹配）；后续接入真实曲库时替换 `filtered()` 即可。

## 应用图标生成

- 源图 `assets/icon/icon.png` 只有 **100×100**，放大到 1024 会明显发虚，理想是提供 ≥1024 的源图再重跑脚本。
- 生成脚本 `scripts/gen_icons.py`（纯标准库 + 系统 `sips`/`iconutil`，无需 Pillow）：
  - `assets/icon/png/icon_{16,24,32,48,64,128,256,512,1024}.png` — 由 1024 母版向下缩放，避免累积误差。
  - `assets/icon/AppIcon.icns` — 经 `AppIcon.iconset`（10 档）→ `iconutil -c icns`。
  - `assets/icon/icon.ico` — 手写 ICO 容器，内嵌 7 档 PNG（16/24/32/48/64/128/256，256 尺寸在目录项记作 0），Vista+ 原生支持 PNG 压缩条目。
- 项目目前没有 bundler 配置（无 cargo-bundle / Tauri），图标尚未被任何打包流程引用。
- 另出 `assets/icon/AppIcon-padded.icns`：按 macOS 图标网格把主体缩到 824、居中放进 1024 透明画布（`sips` 不支持透明 pad，脚本内置极简 PNG 读写自己合成）。原 `AppIcon.icns` 保持无留白。

## 全局字体换成 HarmonyOS Sans

- `assets/fonts` 下的 Geist 已被替换成 5 个字重的 HarmonyOS Sans，`app.rs::bundled_fonts()` 原本用 `include_bytes!` 硬编码 Geist 路径，不改会直接编译失败。
- 族名：`HarmonyOS Sans`（Light 300 / Regular 400 / Bold 700 同族）；`HarmonyOS Sans Thin`(250) 与 `HarmonyOS Sans Black`(900) 在字体内部是**独立族名**，按 weight 900 只会落到 Bold。
- 字体只含 874 个码位、**无任何中文字形**，中文靠系统回退（macOS → PingFang SC）渲染。之前 Geist 同样没有中文、回退正常，故机制已验证。若要中文也是 HarmonyOS 风格需补 `HarmonyOS_Sans_SC.ttf`。
- 字体名统一在 `src/ui/app_theme.rs` 的 `BODY_FONT` / `MONO_FONT` 常量中定义，`theme()` 里写进 `UiFonts`；`UiTheme::set` → `sync_component_theme` 会把 `font_family`/`mono_font_family` 同步给 gpui-kit 组件。
- 全局生效靠 `Player::render` 根 div 上的 `.font_family(theme.fonts.body)`（gpui 沿元素树继承）。
